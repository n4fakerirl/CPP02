# CPP02 - 42 | [FRENCH VERSION] *english below*

## 📚 Description

Le module CPP02 introduit la **Orthodox Canonical Form** et la surcharge d'opérateurs à travers la création d'une classe représentant des nombres à virgule fixe.

---

## 🛠️ Notions abordées

* Constructeur par défaut
* Constructeur de copie
* Opérateur d'affectation
* Destructeur
* Surcharge d'opérateurs
* Fonctions membres `const`

---

## 📂 Exercices

* **ex00** : My First Class in Orthodox Canonical Form
* **ex01** : Towards a more useful fixed-point number class
* **ex02** : Now we're talking
* **ex03** : BSP *(pas dans le dépôt)*

---

## ⚙️ Compilation

| Commande      | Description                                                            |
| ------------- | ---------------------------------------------------------------------- |
| `make`        | Compile l'exercice et génère un exécutable                             |
| `make clean`  | Supprime les fichiers objets (`.o`)                                    |
| `make fclean` | Supprime les fichiers objets **et** l'exécutable                       |
| `make re`     | Supprime les fichiers objets, l'exécutable, puis recompile entièrement |

# CPP02 - 42 | [ENGLISH VERSION]

## 📚 Description

CPP02 introduces the **Orthodox Canonical Form** and **operator overloading** through the implementation of a fixed-point number class.

---

## 🛠️ Concepts Covered

* Default constructor
* Copy constructor
* Copy assignment operator
* Destructor
* Operator overloading
* `const` member functions

---

## 📂 Exercises

* **ex00** : My First Class in Orthodox Canonical Form
* **ex01** : Towards a more useful fixed-point number class
